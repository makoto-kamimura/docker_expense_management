# 残タスク

RingiWoMerge の MVP と拡張機能（[readme 第16章](../../readme.md#16-開発ロードマップ)の Phase 1・Phase 2）は実装済みで、公開デモ（<https://expense.makoto-kamimura.com>）で動いている。
ここには、残っている作業だけをまとめる。仕様は [readme.md](../../readme.md) を、運用の手順は [運用手順書](../runbooks/operation.md) を参照する。

## 1. 本番化（Phase 3）

- [ ] **TLS の終端**（Let's Encrypt + Nginx）
  - `platform/nginx/nginx.conf` に TLS と `server_name` を設定する。本番では `JWT_SECRET`（32文字以上）と `POSTGRES_PASSWORD` を必ず変える。
- [ ] **S3互換ストレージへの切り替え**（MinIO など）
  - 添付・家事の見本画像・リンクプレビューの画像を、API のローカルボリューム（`backend_uploads`）から移す。
- [ ] **DB のバックアップの自動化と、リストアの定期的な確認**
  - 今は `pg_dump` を手動で実行している（運用手順書 3章）。
- [ ] **マイグレーションの仕組み**
  - 今は `migrate.rs` の冪等な SQL を起動のたびに流している（readme 19.1節）。sqlx migrate などの版管理に移すかを決める。
- [ ] **認証の強化**
  - パスワードの再設定（メールの送信）、レート制限、CSRF 対策。OAuth（Google / Microsoft）は readme 未決事項 Q7。
- [ ] **デモアカウントの無効化**
  - 本番に出す前に、`password123` のデモアカウントを変更するか無効にする（readme 17.5節）。
- [ ] **Web のフォームの検証の強化**（zod など）
- [ ] **テスト**
  - 単体テスト（今は家事の集計・ラベルの検証など一部のみ）と、E2E テスト（Playwright）を整える。
- [ ] **CI/CD**
  - lint・テスト・ビルド・デプロイのパイプライン。

## 2. 動作確認

- [ ] **モバイルアプリの実機での確認（Expo SDK 57）**
  - 確認済み：`expo-doctor` 21/21、`tsc --noEmit`、`expo export -p android` のバンドル。
  - やること：SDK 57 は New Architecture 専用なので、SDK 57 に対応した Expo Go か Dev Client で、ログイン・稟議の作成からレシートの OCR まで通す。
- [ ] **リンクプレビューの取得先ごとの見え方**
  - やること：文字コード（Shift_JIS・EUC-JP）や OGP の書き方が特殊な日本語のサイト、主要な EC サイトの商品ページを試す。

## 3. 将来機能

承認のルール・通知・投票・AI・予算・通貨・画面の言語などは、readme の[未決事項](../../readme.md#24-未決事項)で扱う。進め方が決まったら、ここにタスクとして足す。

## タスクの書き方

- 1つの作業を1つのチェックボックスにし、分類ごとの節に足す。必要なら「確認済み」「やること」を下に書く。
- 終わったら `[x]` にして、下の「対応済み」に1行でまとめて移す。
- 仕様が変わるものは、readme も合わせて直す（決定は readme の[決定事項](../../readme.md#23-決定事項)に足す）。

## 対応済み

### 経費精算アプリ（Phase 0。2026-05-28 に 0.1.0 をリリース）

- [x] Docker Compose による起動（db / backend / web / nginx）、Nginx のリバースプロキシ
- [x] Rust API（axum + sqlx）、JWT + Argon2id、初期ユーザーの投入
- [x] 経費の申請・承認・却下、領収書の添付、月次集計と CSV の出力、ロールによる認可
- [x] テナント（組織）の分離、申請ごとの承認者、購入品目の明細、稟議資料の画面
- [x] Web（Next.js）とモバイル（Expo Router）の最小の画面

### RingiWoMerge の MVP（Phase 1）

- [x] 経費精算アプリを RingiWoMerge に作り替え、旧 DB を起動時に移行（旧テーブルは `legacy_*` に退避）
- [x] グループと招待コード、申請者・レビュアー・管理者の権限（リクエストのたびに DB から読む）
- [x] 稟議のワークフロー（下書き → … → マージ → 購入済み / クローズ）、コメント・修正依頼・承認・却下・マージ・購入済み
- [x] アクティビティ、資料とレシートの添付（HEIC 対応）と署名付きの短時間のリンク
- [x] Web：一覧・詳細・まとめ資料・ダッシュボード・設定・オンボーディング。経費の月次集計と CSV は廃止
- [x] モバイル：一覧・作成と編集・詳細・購入済みにする（レシートの OCR）・まとめ資料・ダッシュボード・オンボーディング
